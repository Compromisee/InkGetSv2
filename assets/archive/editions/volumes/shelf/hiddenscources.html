02 / Getting started

Make yourself
at home.

Sources are separate from Inkget. Add the repository to start exploring.

01 /
Open Inkget

Head to Sources, then open repositories.

02 /
Add the collection

Choose the local hidden-sources.json file alongside its sources folder, or use the raw HTTPS URL of the index from GitHub. The repository page URL is not the install URL.

03 /
Start exploring

Hidden sources remain concealed in Inkget until the existing reveal gesture.
